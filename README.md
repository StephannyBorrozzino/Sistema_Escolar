# Sistema Escolar

Projeto de um sistema escolar fictício desenvolvido para uma atividade de Front-end.

## Sobre

Este projeto simula um sistema escolar para gerenciamento de chamadas, alunos e salas de aula. As informações são armazenadas localmente utilizando o localStorage do navegador e podem ser exportadas em formato `.json`.

## Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript

## Como Executar

1. Clone ou baixe o projeto.
2. Abra o arquivo `index.html` em seu navegador.

## Funcionalidades

- Cadastro de alunos, salas e chamadas
- Visualização dos dados cadastrados
- Edição e exclusão de registros
- Histórico de alterações de presença
- Geração de relatórios de alunos, salas e chamadas
- Exportação de dados em formato `.json`
- Navegação entre as seções da aplicação
